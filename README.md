# RielJ's Homebrew tap

```sh
brew install --cask rielj/tap/kakemono   # macOS app, with the kakemono command
brew install rielj/tap/kakemono-cli      # command-line tool only, macOS or Linux
```

The [kakemono release workflow](https://github.com/RielJ/kakemono/blob/main/.github/workflows/packages.yml) updates these files when a release is published. Change the templates in [`packaging/homebrew`](https://github.com/RielJ/kakemono/tree/main/packaging/homebrew) instead of editing them here.
